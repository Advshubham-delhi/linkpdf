      Google setup steps
      1. In Google Cloud Console, create a project and enable the Google Drive API.
      2. OAuth consent screen: choose External, add your own Google account as a test user, and add the scopes drive.readonly and drive.appdata.
      3. Credentials → Create credentials → OAuth client ID → Web application. Add the origin shown above.
      4. Paste the client ID here, tap Save, then tap Drive in the top bar.
